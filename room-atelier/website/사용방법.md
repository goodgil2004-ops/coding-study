# 룸 아틀리에 — 3D 공간 편집기

3D 모델을 가져와 배치하고, 가구를 직접 만들고, 방 윤곽과 가벽을 편집하는 웹앱입니다.

## Windows에서 실행
1. 압축 파일을 풀고 `START.cmd`를 실행합니다.
2. 브라우저에서 http://127.0.0.1:4173 을 열고 ‘공간 꾸미기 시작’을 누릅니다. 편집기는 http://127.0.0.1:4173/editor.html 에서 바로 열 수 있습니다.
3. 종료하려면 터미널에서 Ctrl+C를 누릅니다.

Node.js 또는 이 PC의 Codex 내장 Node 실행 환경을 사용합니다. 다른 운영체제에서는 이 폴더에서 `node server.cjs`를 실행하세요. `index.html`을 파일로 직접 열면 브라우저의 모듈 보안 정책 때문에 동작하지 않습니다.

## 3D 모델 가져오기
- GLB, glTF, OBJ, STL 지원. 형상과 재질이 하나로 묶인 GLB를 권장합니다.
- glTF에 외부 BIN·이미지가 있으면 함께 선택하세요. OBJ 재질을 쓰려면 MTL·이미지도 함께 선택합니다.
- 모델과 관련 파일을 합쳐 25MB, 삼각형 150만 개까지 지원합니다.
- OBJ·STL은 단위가 일정하지 않으므로 실제 가로·세로·높이를 확인하세요. 축 방향이 다르면 가져오기 창에서 X축 90° 버튼을 누르세요.
- Draco 및 Meshopt 형상 압축을 지원합니다. KTX2 텍스처, FBX, BLEND 파일은 PNG/JPG 텍스처를 포함한 GLB로 변환해서 사용하세요.
- 애니메이션을 재생하는 뷰어가 아니라 정적인 가구 배치 도구입니다.
- `samples/sample-desk.glb`로 가져오기를 바로 시험할 수 있습니다.

## 가구 직접 만들기
- ‘가구 직접 만들기’에서 책상·의자·책장 형태로 시작하거나 도형 하나로 시작합니다.
- 직육면체·원기둥·구·원뿔을 추가하고 크기, 위치 XYZ, 회전 XYZ, 색상을 조절합니다.
- 도형을 드래그하면 바닥과 평행하게 이동합니다. 높이는 Y 값을 바꿉니다.
- 복제·삭제·되돌리기·다시 실행을 지원합니다. 도형은 최대 80개입니다.
- 완성하면 하나의 가구로 방에 배치됩니다. 이후 ‘구성 도형 편집’으로 다시 수정할 수 있습니다.
- GLB 내보내기를 지원합니다. 기본 가구도 선택 후 ‘선택한 모델 GLB 저장’으로 파일로 만들 수 있습니다.
- 정점·면 직접 편집이나 불리언 연산을 제공하는 전문 CAD 도구는 아닙니다.

## 방과 벽
- 방의 가로·세로는 200–1200cm, 천장 높이는 200–450cm입니다.
- 직사각형, L자형, 직접 그린 윤곽을 사용할 수 있습니다.
- 윤곽 편집에서는 격자에 점을 순서대로 찍고 점을 끌어서 이동합니다. 10cm 단위, 3–20개 꼭짓점이며 벽이 교차하는 윤곽은 차단합니다.
- 가벽·문 개구부가 있는 벽·창 개구부가 있는 벽을 추가하고 길이·두께·높이·회전·개구부 치수를 바꿉니다.
- 시야를 가리는 가까운 외벽은 자동으로 숨겨집니다. 가벽은 계속 표시됩니다.
- 가구끼리 또는 가벽과의 충돌은 막지 않습니다. 실제 배치 가능 여부는 치수와 통로를 확인하세요.

## 배치와 저장
- 가구 드래그: 5cm 단위 이동. 오른쪽 패널에서 더 정확한 값을 입력할 수 있습니다.
- 빈 곳 드래그: 시점 회전. 휠: 확대. 평면 뷰와 외벽 표시 전환도 가능합니다.
- 바닥에서 띄우기: 선반·조명처럼 높이가 필요한 물건을 위로 올립니다.
- Ctrl+Z: 실행 취소. Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행. R: 90도 회전. Delete: 삭제. Esc: 선택 해제.
- ‘공간 저장’은 모델 원본을 포함해 이 브라우저의 IndexedDB에 저장합니다. 다른 주소·기기와 자동 동기화하지 않습니다.
- ‘파일 저장’은 모델을 포함한 JSON 공간 파일을 내보냅니다. 폴더 아이콘으로 다시 불러옵니다. 공간 파일 가져오기는 최대 120MB입니다.
- 브라우저 저장 용량은 환경에 따라 다릅니다. 중요한 공간은 파일로도 저장해 두세요.
- 카메라 아이콘은 현재 3D 화면을 PNG로 저장합니다.
- 미리보기에서 정한 570 × 420 × 280cm 공간은 `my-room.room.json`에 담겨 있고, 저장된 공간이 없는 환경의 시작 공간으로도 사용됩니다.

## 기본 가구와 기술
기본 가구는 다운로드한 완제품 모델이 아니라 Three.js로 치수에 맞춰 생성한 모델입니다. 외부 AI API 키와 서버 데이터베이스는 필요하지 않습니다. 3D 파일과 공간 데이터는 브라우저에서 처리됩니다.

소스: `dist/index.html`·`dist/home.css` (홈페이지), `dist/editor.html`·`dist/style.css` (편집기 화면), `dist/app.js` (공간), `dist/models.js` (가져오기·저장), `dist/builder.js` (제작실), `dist/outline.js` (방 윤곽).
Three.js 0.170.0 및 관련 MIT 라이선스 코드는 `dist/vendor/`에 포함됩니다. 글꼴은 Google Fonts를 사용하며 인터넷 연결이 없으면 시스템 글꼴로 표시합니다.
