# 룸 아틀리에 · 자동저장 1.2.0

room-atelier-android-1.2.0.apk를 Android 8.0 이상 기기에서 설치합니다. 최신 Android System WebView가 필요합니다.

기존 개인 서명키가 제공되지 않아 새 서명키와 별도 패키지(io.goodg.roomatelier.autosave)를 사용합니다. 기존 앱을 삭제할 필요가 없습니다. 이전 앱에서 공간 파일(.room.json)을 내보내고 새 앱의 폴더 버튼으로 불러오세요.

가구·방 변경을 자동 저장하고, 최근 변경은 동기식 복구 사본으로도 보관합니다. 앱 전환·페이지 종료 시 저장을 요청합니다. 일반적인 새로고침 및 재실행 후 복원하도록 구현했습니다. 저장 공간 부족, 앱 삭제, 앱 데이터 지우기까지 보호하지는 않습니다. 중요한 작업은 공간 파일로 내보내 보관하세요. 가구 제작실에서 아직 '방에 추가'하지 않은 편집 초안은 저장 대상이 아닙니다.

포함: 데스크테리어 12종, 생활가전 세탁기·전자레인지, 사진 생성 기능 제거, 자동 저장·복원, 드래그 시 물체 높이 유지.

빌드: 원본 APK의 네이티브 DEX를 그대로 재사용하고 최신 웹 자산과 변경된 manifest를 재패키징했습니다. 이 환경에서는 Android SDK 전체를 사용할 수 없어 Java를 다시 컴파일하지 않았습니다. repackage.py는 Python cryptography로 APK v2 서명을 생성합니다. apksigtool로 독립 서명 검증을 수행했습니다. 서명·ZIP CRC·리소스 정렬·코드 테스트는 확인했으며, 실제 Android 설치/실행 테스트는 하지 못했습니다.

재생성: cryptography 설치 후 `python3 repackage.py`. 기존 키가 있으면 재사용합니다. 향후 같은 앱 업데이트에는 동일한 `.signing/release.pem`이 필요합니다.

이 한국어 주석 소스에는 개인 서명키가 포함되지 않습니다. 기존 배포 APK와 같은 서명으로 업데이트하려면 별도로 보관된 기존 키가 필요합니다.
