# 룸 아틀리에 iPhone / iPad

Safari에서 배포 주소를 열고 본인 계정으로 로그인합니다. 편집기에 진입한 뒤 공유 메뉴 → 홈 화면에 추가를 선택합니다. ‘웹 앱으로 열기’가 표시되면 켜 둡니다.

- 인터넷 연결이 필요한 웹 앱입니다. App Store 앱 또는 IPA 파일이 아닙니다.
- 공간 저장은 해당 브라우저/앱의 기기 내부 저장소를 사용합니다. 자동 기기 간 동기화는 없습니다.
- Android에서 파일 저장으로 내보낸 `.room.json`을 iPhone으로 옮긴 뒤 폴더 버튼으로 불러올 수 있습니다.
- 파일 내보내기는 iOS에서 저장 창을 띄웁니다. ‘공유 · 파일에 저장’을 누르거나 다운로드를 이용합니다.
- 홈 화면 앱과 Safari 간 저장 상태가 다를 수 있으므로, 중요한 공간은 JSON 파일로 내보내 보관합니다.

변경: 홈 화면 메타데이터와 아이콘, 작은 화면의 파일 열기 버튼, 안전 영역 여백, iOS 입력 확대 방지, 비동기 파일 생성 후 사용자의 탭으로 공유 실행, 다운로드 URL의 해제 지연.

검증: 기존 모델/방 윤곽 테스트, JavaScript 문법 검사. 이 실행 환경에는 Safari/WebKit 브라우저와 실제 iPhone이 없어 실제 iOS의 3D 렌더링 및 공유 메뉴 검증은 하지 못했습니다.
